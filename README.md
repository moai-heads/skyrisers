# SKYRISERS

An endless SimTower-style tower builder that runs in the browser. Single file, no assets, no build step.

Play: https://moai-heads.github.io/skyrisers/

## How it works
- Floors go up forever; land cost grows exponentially.
- Rooms only fill if they can reach the Lobby via stairs/elevators in the same column.
- Expand the tower by keeping the top floor 50%+ full with happiness 40+.
- The city grid supplies only 2 power — build Generators, or your top floors brown out.
- Amenities (park/gym/diner/arcade) raise neighbour happiness; rent scales with height.
- Random events: elevator jams, blackouts, hype booms, inspections, pest infestations, demand spikes.

## Controls
- Left click: build the selected tool. Right click / X: raze (50% refund).
- Mouse wheel or arrow keys: scroll floors. `1`-`0`: pick tools. Space: pause.
