# SKYRISERS

An endless SimTower-style tower builder that runs in the browser. Single file, no assets, no build step.

Play: https://moai-heads.github.io/skyrisers/

## The tower
- Ground floor (G) sits on dirt. Two **basements** (B1/B2) are dug for you — Storage and Generators live down there.
- Rooms only fill if they can reach the **Lobby** via stairs/elevators **in the same column**.
- `BUILD UP ▲` unlocks the next floor: needs funds, 50% occupancy on the top floor, and happiness 40+. Land cost grows exponentially — forever.
- `WIDEN ▶` buys two more bays of land, so the tower grows sideways too (up to 24 bays).

## Twists over the original
- **Power grid**: the city only supplies 2. Generators give +6 each; load is shed from the **top down**.
- **Amenity adjacency**: parks/gyms/diners/arcades radiate happiness; shops want footfall near transport.
- **Endless pressure**: city demand drifts randomly, so a condo tower can suddenly have nowhere to go.
- **Events**: elevator jams, blackouts, hype (×1.5 income), inspections, pests, demand spikes.

## Controls
- **Left click** build · **right click** raze (50% refund) · right/middle **drag** pans the camera
- **Wheel** zoom (0.6×–6×) · **+ / −** zoom buttons · **WASD / arrows** pan · **F** fit view · **T** follow the top
- **1–0, G, V** pick tools · **X** raze · **Q** inspect · **Space** pause · speed 1×/2×/4×
- Sidebars minimise: `◧ Build`, `Stats ◨`, `⛶ Clean view` in the top bar.
